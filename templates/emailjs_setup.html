Step 1 — Create EmailJS Account

EmailJS is free — 200 emails/month, no server needed.

Open EmailJS.com →
Step 2 — Connect Gmail
  1. Login to EmailJS dashboard
  2. Go to Email Services → Add New Service
  3. Choose Gmail
  4. Click Connect Account → allow permissions
  5. Note your Service ID (looks like: service_xxxxxx)
Step 3 — Create Monthly Report Template
  1. Go to Email Templates → Create New
  2. Name it: MyVault Monthly Report
  3. Set To Email: {{"{{"}}to_email{{"}}"}}
  4. Set Subject: MyVault Report — {{"{{"}}month_name{{"}}"}}
  5. Paste the body below into the template
  6. Note your Template ID (looks like: template_xxxxxx)
Hi {{"{{"}}to_name{{"}}"}}, Here is your MyVault report for {{"{{"}}month_name{{"}}"}}. FINANCIAL SUMMARY ───────────────── Income: {{"{{"}}monthly_income{{"}}"}} Expenses: {{"{{"}}monthly_expense{{"}}"}} {{"{{"}}balance_label{{"}}"}}: {{"{{"}}balance{{"}}"}} Savings Rate: {{"{{"}}savings_rate{{"}}"}} TOP SPENDING CATEGORIES ─────────────────────── {{"{{"}}top_categories{{"}}"}} UPCOMING RENEWALS ───────────────── {{"{{"}}upcoming_renewals{{"}}"}} Stay on track! — MyVault
Step 4 — Create Renewal Reminder Template
  1. Create another template named: MyVault Renewal Reminder
  2. Set To Email: {{"{{"}}to_email{{"}}"}}
  3. Set Subject: 🔔 Renewal Reminder — {{"{{"}}sub_name{{"}}"}}
  4. Paste body below and note its Template ID
Hi {{"{{"}}to_name{{"}}"}}, Reminder: {{"{{"}}sub_name{{"}}"}} renews in 2 days. Amount: {{"{{"}}sub_amount{{"}}"}} Renewal Date: {{"{{"}}renewal_date{{"}}"}} Log into MyVault to manage it. — MyVault
Step 5 — Get Your Public Key
  1. In EmailJS dashboard → Account → General
  2. Copy your Public Key
Step 6 — Add Keys to Render

Go to your Render dashboard → MyVault service → Environment → add these:

EMAILJS_SERVICE_IDservice_xxxxxx
EMAILJS_TEMPLATE_IDtemplate_xxxxxx (monthly report)
EMAILJS_REMINDER_TEMPLATE_IDtemplate_xxxxxx (renewal reminder)
EMAILJS_PUBLIC_KEYyour_public_key

After adding keys, click Save Changes → Render will redeploy automatically.
